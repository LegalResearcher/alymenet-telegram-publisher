# ناشر منشورات @reuters_Ar إلى قناتك

ينشئ هذا المشروع نسخة من المنشورات الجديدة الظاهرة في صفحة المعاينة العامة لقناة `@reuters_Ar`، ثم ينشر النص والصور أو الفيديوهات المتاحة عبر Telegram Bot API في قناتك. لا يستخدم Userbot أو بيانات دخول حساب شخصي.

يُنشر الخبر بهذا القالب:

```text
نص الخبر
ــــــــــــــــــــــــــــ
للاشتراك بالقناة عبر تيليجرام:
https://t.me/hasadalyoum
```

يحافظ السكربت على الرموز التعبيرية والرموز الموجودة في بداية الخبر العربي، ويحذف النسخة الإنجليزية وعبارة تاريخ Reuters ورابط القناة المصدر، ثم يرسل النص بخط عريض.

يتجاهل تلقائيًا أي منشور يحتوي على اسم قناة **اليمن نت** أو رابطها `https://t.me/ALYMENET`، مع تطبيق فحص نهائي قبل الإرسال أيضًا.

## الإعداد

1. أنشئ بوتًا عبر `@BotFather`.
2. أضف البوت مشرفًا في قناتك مع صلاحية نشر الرسائل.
3. في إعدادات المستودع، افتح **Settings → Secrets and variables → Actions**.
4. أضف Secret باسم `TELEGRAM_BOT_TOKEN` وضع فيه توكن البوت.
5. أضف Variable باسم `TELEGRAM_CHANNEL_ID` وضع فيه معرف قناتك، مثل `@my_channel`.
6. من تبويب **Actions** شغّل Workflow يدويًا أولًا للاختبار.

بعد ذلك يحاول GitHub Actions التشغيل كل خمس دقائق. قد تؤخر GitHub المهام المجدولة قليلًا، لذلك لا يُعد هذا نقلًا فوريًا مضمونًا.

## الاختبار المحلي

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="توكن_البوت"
export TELEGRAM_CHANNEL_ID="@معرف_قناتك"
python alymenet_to_telegram.py
```

## ملاحظات

- يعتمد المشروع على صفحة المعاينة العامة `https://t.me/s/reuters_Ar`، وقد يتوقف إذا غيّر Telegram تصميم الصفحة أو فرض قيودًا.
- ينقل النص والصور أو الفيديوهات التي تظهر روابطها في صفحة المعاينة العامة. بعض أنواع الملفات والألبومات قد لا تكون قابلة للاستخراج دون Userbot.
- يذكر المصدر ورابط المنشور الأصلي.
- يجب احترام حقوق إعادة النشر وشروط Telegram.
- لا تضع التوكن في الملفات أو الكود أو Issues أو سجلات Actions.
